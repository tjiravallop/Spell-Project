# คาถานอกตำรา · Spell Foundry

เกมประกอบคำร่ายเวทแบบเทิร์นเบส รองรับเมาส์ สัมผัส และคีย์บอร์ด ใช้ HTML/CSS/JavaScript กับ Canvas 2D ไม่มี dependency และไม่มีขั้นตอน build

## เปิดเล่น

ต้องมี Node.js ที่รองรับ ES modules และ `node:test` (เครื่องพัฒนาใช้ Node 26)

บน Windows ดับเบิลคลิก `OPEN_GAME.cmd` เพื่อเปิดเซิร์ฟเวอร์และเกมในเบราว์เซอร์

เปิดเทอร์มินัลในโฟลเดอร์โครงการ แล้วรัน `npm start` หรือ `npm.cmd start` บน PowerShell

เปิด [เกมในเครื่อง](http://localhost:4173) ในเบราว์เซอร์ หากต้องการทดสอบบนมือถือใน Wi-Fi เดียวกัน ให้ใช้ IP ของคอมพิวเตอร์แทน localhost และอนุญาตพอร์ตตามการตั้งค่าเครือข่ายของคุณ

ใช้เว็บเซิร์ฟเวอร์ static อื่นได้เช่นกัน ไม่ควรเปิดผ่าน `file://` เพราะ ES modules และการบันทึกอาจไม่ทำงาน ใช้ origin และพอร์ตเดิมเพื่ออ่านเซฟเดิม

หน้าต่อสู้แสดงสนามพร้อมเจตนาศัตรู แท่นร่าย และมือไพ่ในมุมมองเดียว มือไพ่เลื่อนด้านข้างบนจอเล็ก ใช้ปุ่มมุมขวาบนเปิดตำรา กระเป๋า แผนที่ หรือบันทึกในแผงลอย สูตรที่ยังไม่ค้นพบต้องทดลองร่ายจริง หากผิดจะเสียไพ่ มานา และเทิร์น

## วิธีเล่น

- แตะหรือคลิกคำเพื่อวางในช่องถัดไป หรือจับด้ามจุดข้างคำเพื่อลาก
- คลิกช่องเพื่อเลือกตำแหน่งแทรก เมื่อครบสี่ช่องแล้ว การเลือกคำใหม่จะเปลี่ยนคำในช่องที่เลือก
- ย้ายซ้าย/ขวา ลบคำ หรือล้างคาถาด้วยปุ่มใต้ช่อง
- เลือกศัตรูด้วยปุ่มใต้สนาม แล้วอ่านผลคาดการณ์ก่อนร่าย
- เริ่มด้วย 5 คำ ไต่หอถึงชั้น 50 ช่วงเปิดเกมชั้นละสองศึกย่อยและบอส มีจุดพักและรางวัลระหว่างทาง รวมการ์ด 35 คำ
- `ลูก ไฟ คู่` ยิงสองลูก เลือกเป้าแยกได้ ส่วน `ลูก ไฟ คู่ น้ำแข็ง` ยิงลูกเดียวผสานสองธาตุ
- ก่อนขึ้นชั้นถัดไปจัดชุดคำได้ พกสูงสุด 7 คำ การ์ดที่สะสมเก็บข้ามรอบ
- โล่กัน 6 และคงส่วนที่เหลืออีกหนึ่งเทิร์น ป้องกันพื้นฐานกัน 3 โดยไม่ใช้มานา
- มานาฟื้น 3 ในเทิร์นถัดไป ศัตรูเริ่มคลั่งในเทิร์น 7 หรือเทิร์น 8 ตั้งแต่ชั้น 31
- Tab ย้ายโฟกัส Enter/Space ใช้ปุ่ม ทุกการแก้คำมีปุ่มรองรับโดยไม่ต้องลาก
- ปุ่มพักเกมตั้งเสียง ลดการเคลื่อนไหว และกลับหน้าหลักได้

## ทดสอบ

```powershell
npm test
```

ชุดทดสอบครอบคลุมการแปลคาถา ทดลองร่ายแล้วเฟล ธาตุผสาน การเลือกเป้า ม่าน เกราะ การ์ดคำ เซฟ และเส้นทางถึงชั้น 50 ดูผลจำลองช่วงชั้น 31–50 ใน [ROADMAP.md](ROADMAP.md); `TEST_REPORT.md` เก็บผลทดสอบจากรุ่นก่อน

## ข้อมูลและเซฟ

เซฟใช้ localStorage ในเบราว์เซอร์นี้เท่านั้น มีสถานะล่าสุดและสำเนาก่อนหน้า การล้างข้อมูลเว็บไซต์หรือเปลี่ยน origin จะทำให้ไม่พบเซฟเดิม หากเขียนไม่ได้ เกมจะยังเล่นต่อในแท็บปัจจุบันและแสดงข้อความแจ้ง

รายละเอียดกฎและขอบเขตอยู่ใน `GAME_PLAN.md` ภาพและเสียงสร้างจากโค้ดต้นฉบับของโปรเจกต์ ดู `assets/manifest.json` สำหรับที่มา

## เผยแพร่

อัปโหลด `index.html`, `styles.css`, `battle-ui.css`, โฟลเดอร์ `src/` และ `assets/` ไปยัง static hosting ที่รองรับ HTTPS ได้โดยตรง ตัวเกมไม่เรียก API ภายนอก

## เวอร์ชันผสานสไปรต์

นำเกมเวอร์ชันใหม่เป็นฐาน แล้วเพิ่มสไปรต์ผู้จารอาคม อิมพ์หมึก หยดหมึก ปูเกราะปริซึม และผู้เฝ้าชั้นหนึ่งจากต้นแบบ โดยผูกท่าร่าย โจมตี สถานะกระดอง และม่านแตกกับเหตุการณ์ต่อสู้เดิม หากโหลดภาพไม่ได้จะใช้ภาพวาดจากโค้ดเดิม ผู้ร่ายยังใช้ภาพเดิมสำหรับโดนตีและล้ม

Rig, exporter และสไปรต์ทางเลือกนักเวทสุริยัน/ผู้เฝ้าราตรีเก็บใน `assets/caster-rig`, `assets/floor1-monsters`, `assets/prism-crab` และ `assets/floor1-warden-v2` การเปลี่ยนชุดผู้ร่ายยังไม่มีหน้าตั้งค่า

รัน `npm start` จากโฟลเดอร์นี้และเปิด http://localhost:4173 ใช้ origin เดิมหากต้องการอ่านเซฟเดิม การทดสอบชุดผสานใช้พอร์ต 4191 จึงมีเซฟทดสอบแยกจากพอร์ต 4173

เพิ่มต้นแบบมอนชั้น 2–3: โกเลมไส้ตะเกียง ผู้พิทักษ์หอเหล็ก อัศวินหม้อเหล็ก ผู้ถือม่าน บรรณารักษ์เชื้อรา และตำราต้องห้าม Rig และตัวส่งออกอยู่ใน `assets/floor2-golems` และ `assets/floor3-monsters` พร้อมหน้าตัวอย่างท่าที่ใช้ตัววาดจริงของเกม

เพิ่มต้นแบบมอนและบอสชั้น 5–8 จำนวน 7 แบบ ไฟล์ Rig และตัวส่งออกอยู่ใน `assets/floor5-8` พร้อมหน้าตัวอย่างที่ใช้ตัววาดสนามเกม
